Self-hosted web fonts (Latin subset, WOFF2), served from this site instead of Google Fonts.

  Barlow Condensed 500/600/700/800   SIL Open Font License 1.1   https://github.com/jpt/barlow
  DM Mono 400/500                    SIL Open Font License 1.1   https://github.com/googlefonts/dm-mono
  Space Grotesk (variable 300-700)   SIL Open Font License 1.1   https://github.com/floriankarsten/space-grotesk

The files are the Latin subsets Google Fonts serves for these families. The @font-face rules are at
the top of static/css/site-v5.css; the three most-used files are preloaded in templates/base.html.
To change a weight, add the matching .woff2 here and a matching @font-face rule.
